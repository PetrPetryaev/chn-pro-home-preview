# ChangeNOW Pro — главная

Статическая сборка одной страницы: главная кабинета Pro с переключателем версий
**v1 / v2** и состояний **пустой баланс / с деньгами**.

Страница живая: суммы считаются, направления свопа подставляются в поля,
карточки первого блока переключаются кликом.

Собрано из витрины дизайн-системы CHN 2026 отдельной точкой входа — в бандл
попала только эта страница и её зависимости.
